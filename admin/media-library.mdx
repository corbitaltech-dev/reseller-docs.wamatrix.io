<Info>
  **Tenant Media is available only to the account owner.** It cannot be given to staff through roles.
</Info>

## My Media

**My Media** is your personal file library. You can store images and documents used in the admin panel, such as email templates and banners.

<Frame caption="My Media, with the upload controls and the storage meter">
  <img src="/images/admin/media-my-media.png" alt="My Media, with the upload controls and the storage meter" />
</Frame>

<Note>
  Tenants cannot access your files. Each tenant has a separate media library in their workspace.
</Note>

### What you can do

- **Upload** files and organize them into folders.
- **Delete** single or multiple files.
- **Copy file URL** to use a file elsewhere in the platform.

### Storage usage

The storage card shows the total storage used by your platform and tenants. The indicator changes to:

- **Amber** when usage is above 75%.
- **Red** when usage is above 90%.

<Tip>
  Use **Tenant Media** to find which tenants are using the most storage.
</Tip>

## Tenant Media

**Media Library → Tenant Media** shows storage usage for all tenants.

<Frame caption="Tenant Media, with the storage summary cards and per-tenant usage">
  <img src="/images/admin/media-tenant-media.png" alt="Tenant Media, with the storage summary cards and per-tenant usage" />
</Frame>

The page provides summary cards for **Total Tenants**, **Storage Used**, **Total Files**, and **Near Limit**.

### Tenant list

| Column | Description |
| ------ | ----------- |
| **Tenant** | Tenant name. |
| **Plan** | Tenant's current plan. |
| **Usage** | Storage used by the tenant. |
| **Files** | Number of files stored by the tenant. |
| **Last Sync** | Last time the storage information was updated. |

<Note>
  Storage information is updated periodically, not in real time. **Last Sync** shows when the information was last updated.
</Note>

### View tenant files

Open a tenant to view their files. You can open a file, copy its URL, or delete it.

<Warning>
  Deleting a tenant's file is permanent. Only delete tenant files when necessary or when the tenant has requested it.
</Warning>
