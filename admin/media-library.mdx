**Media Library** contains two sections:

- **My Media** — Manage your own files.
- **Tenant Media** — View storage usage for all customers.

<Info>
  **Tenant Media is available only to the account owner.** It cannot be given to staff through roles.
</Info>

## My Media

**My Media** is your personal file library. You can store images and documents used in the admin panel, such as email templates and banners.

Customers cannot access your files. Each customer has a separate media library in their workspace.

### What you can do

- **Upload** files and organize them into folders.
- **Delete** single or multiple files.
- **Copy file URL** to use a file elsewhere in the platform.

### Storage usage

The storage card shows the total storage used by your platform and customers.

The indicator changes to:

- **Amber** when usage is above 75%.
- **Red** when usage is above 90%.

Use **Tenant Media** to find which customers are using the most storage.

## Tenant Media

**Media Library → Tenant Media** shows storage usage for all customers.

The page provides these summary cards:

- **Total Tenants**
- **Storage Used**
- **Total Files**
- **Near Limit**

### Customer list

| Column        | Description                                    |
| ------------- | ---------------------------------------------- |
| **Tenant**    | Customer name.                                 |
| **Plan**      | Customer's current plan.                       |
| **Usage**     | Storage used by the customer.                  |
| **Files**     | Number of files stored by the customer.        |
| **Last Sync** | Last time the storage information was updated. |

<Note>
  Storage information is updated periodically, not in real time. **Last Sync** shows when the information was last updated.
</Note>

### View customer files

Open a customer to view their files.

You can:

- Open a file.
- Copy its URL.
- Delete a file.

<Warning>
  Deleting a customer's file is permanent. Only delete customer files when necessary or when the customer has requested it.
</Warning>
