The Templates API gives you programmatic access to the message templates in a workspace — list approved templates for use in campaigns, or submit new templates for Meta's review.

<Tip>
  Templates approved in one language do **not** automatically apply to other languages. If you need to send the same template in multiple languages, submit a separate template for each language code (e.g. submit `summer_sale_announcement` once with `"language": "en"` and again with `"language": "es"`).
</Tip>

---

## GET /workspaces/{workspace_id}/templates

List all message templates in a workspace, with optional filtering by status, category, and pagination.

### Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique ID of the workspace whose templates you want to list.
</ParamField>

### Query Parameters

<ParamField query="status" type="string">
  Filter templates by their Meta review status. Accepted values: `pending`, `approved`, `rejected`, `paused`.
</ParamField>

<ParamField query="category" type="string">
  Filter templates by category. Accepted values: `marketing`, `utility`, `authentication`.
</ParamField>

<ParamField query="page" type="integer">
  Page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer">
  Number of results per page. Defaults to `20`. Maximum is `100`.
</ParamField>

### Request

```bash List approved marketing templates
curl -X GET "https://api.wamatrix.io/v1/workspaces/ws_01hx3g5r8f0q2k7d/templates?status=approved&category=marketing" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

### Response

```json
{
  "data": [
    {
      "id": "tpl_3a1b2c4d5e",
      "name": "summer_sale_announcement",
      "category": "marketing",
      "language": "en",
      "status": "approved",
      "body": "Hi {{1}}, our summer sale is live — up to 50% off. Shop now before it ends!",
      "created_at": "2024-05-20T10:00:00Z"
    }
  ]
}
```

## GET /workspaces/{workspace_id}/templates/{template_id}

Retrieve the full details of a single template, including all components and, if the template was rejected, the rejection reason provided by Meta.

### Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique ID of the workspace.
</ParamField>

<ParamField path="template_id" type="string" required>
  The unique ID of the template to retrieve (e.g. `tpl_3a1b2c4d5e`).
</ParamField>

### Request

```bash Get a template
curl -X GET https://api.wamatrix.io/v1/workspaces/ws_01hx3g5r8f0q2k7d/templates/tpl_3a1b2c4d5e \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

### Response

```json
{
  "data": {
    "id": "tpl_3a1b2c4d5e",
    "name": "summer_sale_announcement",
    "category": "marketing",
    "language": "en",
    "status": "approved",
    "rejection_reason": null,
    "components": [
      {
        "type": "header",
        "format": "text",
        "text": "🌞 Summer Sale is here!"
      },
      {
        "type": "body",
        "text": "Hi {{1}}, our summer sale is live — up to 50% off. Shop now before it ends!"
      },
      {
        "type": "footer",
        "text": "Reply STOP to opt out."
      },
      {
        "type": "buttons",
        "buttons": [
          { "type": "url", "text": "Shop Now", "url": "https://yourstore.com/sale" }
        ]
      }
    ],
    "created_at": "2024-05-20T10:00:00Z"
  }
}
```

## POST /workspaces/{workspace_id}/templates

Submit a new message template for Meta's review. Templates are reviewed by Meta, typically within 24 hours. Once approved, they are available for use in messages and campaigns.

### Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique ID of the workspace to submit the template in.
</ParamField>

### Body Parameters

<ParamField body="name" type="string" required>
  The template name. Must be lowercase with underscores and no spaces (e.g. `order_confirmation_v1`). This name is used when sending messages and cannot be changed after submission.
</ParamField>

<ParamField body="category" type="string" required>
  The template category, which affects Meta's review criteria and messaging policies. Accepted values: `marketing`, `utility`, `authentication`.
</ParamField>

<ParamField body="language" type="string" required>
  The language code for this template (e.g. `en`, `es`, `pt_BR`, `ar`). Submit a separate template for each language you need.
</ParamField>

<ParamField body="components" type="array" required>
  An ordered array of component objects that define the template structure. Supported component types:

  | Type | Description |
  |---|---|
  | `header` | Optional. Supports `format: "text"`, `"image"`, `"video"`, or `"document"`. |
  | `body` | Required. The main message text. Use `{{1}}`, `{{2}}`, etc. for variable placeholders. |
  | `footer` | Optional. Short text shown below the body (e.g. opt-out instructions). |
  | `buttons` | Optional. Up to 3 buttons of type `url`, `phone_number`, or `quick_reply`. |
</ParamField>

### Request

```bash Submit a template for approval
curl -X POST https://api.wamatrix.io/v1/workspaces/ws_01hx3g5r8f0q2k7d/templates \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "summer_sale_announcement",
    "category": "marketing",
    "language": "en",
    "components": [
      {
        "type": "header",
        "format": "text",
        "text": "🌞 Summer Sale is here!"
      },
      {
        "type": "body",
        "text": "Hi {{1}}, our summer sale is live — up to 50% off. Shop now before it ends!"
      },
      {
        "type": "footer",
        "text": "Reply STOP to opt out."
      },
      {
        "type": "buttons",
        "buttons": [
          { "type": "url", "text": "Shop Now", "url": "https://yourstore.com/sale" }
        ]
      }
    ]
  }'
```

### Response

```json
{
  "data": {
    "id": "tpl_9e8d7c6b5a",
    "name": "summer_sale_announcement",
    "category": "marketing",
    "language": "en",
    "status": "pending",
    "created_at": "2024-06-15T12:00:00Z"
  }
}
```

## DELETE /workspaces/{workspace_id}/templates/{template_id}

Delete a template. Only templates with status `rejected` or `draft` can be deleted via the API. Templates with status `approved` or `pending` cannot be deleted from the API — manage those through the workspace dashboard.

### Path Parameters

<ParamField path="workspace_id" type="string" required>
  The unique ID of the workspace.
</ParamField>

<ParamField path="template_id" type="string" required>
  The unique ID of the template to delete.
</ParamField>

### Request

```bash Delete a template
curl -X DELETE https://api.wamatrix.io/v1/workspaces/ws_01hx3g5r8f0q2k7d/templates/tpl_9e8d7c6b5a \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

### Response

```json
{
  "data": {
    "deleted": true
  }
}
```
