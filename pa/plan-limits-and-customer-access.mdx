description: "Understand how plans control tenant features and usage limits."

---

A tenant's plan controls which features they can use and how much they can use them, such as contacts, campaigns, channels, and AI requests.

## When a feature is not included

If a feature is not included in the tenant's plan, it with a lock icon. Selecting it shows an upgrade option because a **higher plan** includes it.

## When a tenant reaches a limit

A tenant cannot exceed the limit set by their plan. Depending on the feature, they may see:

- An error when trying to use the feature.
- A message showing the limit before starting an action.
- A warning when they are close to the limit.
- An **Upgrade Plan** option if a higher plan provides a higher limit.

<Warning>
  A downgrade does not take effect immediately. The tenant keeps their current plan and access until the next renewal. They can cancel the downgrade before then.
</Warning>

## Tenant usage

Tenants can view their usage from **My Subscription**. The **What's included** section shows the features included in their plan, current usage, and allowed limits.

| Example | What it means |
| --- | --- |
| **500 / 1,000 Contacts** | Shows current usage compared with the contact limit. |
| **Unlimited Channels** | The plan has no limit for channels. |

A progress bar and status label show how close the tenant is to each limit.

## Creating a plan

When creating a plan, you choose the features to include and set the limit for each feature. The platform automatically handles locked features and usage warnings. These behaviours cannot be changed from the plan form.
