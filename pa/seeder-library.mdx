A new tenant starts with an empty workspace. Stock this library with ready-made **Automations** and **WhatsApp Flows**, and they have something to use from day one.

Click **Setup → Seeder Library** in the sidebar to see what you are offering them.

## Collection list

<Frame caption="The Seeder Library list, with each collection's type, source and availability switch">
  <img src="/images/pa/seeder-library-list.png" alt="The Seeder Library list, with each collection's type, source and availability switch" />
</Frame>

| Column | Description |
| ------ | ----------- |
| **Name** | What tenants see in their workspace. |
| **Type** | **Automation**, **WhatsApp Flow**, or **Template**. |
| **Seeder Key** | The collection's own id. Importing the same key again updates that collection instead of making a second one. |
| **Source** | **Platform** if it came with WaMatrix.io, or **Own** if you built or imported it. This decides what you can edit. |
| **Available to Customers** | Whether tenants can see and use it. |

<Info>
  Every collection starts hidden. Nothing reaches your tenants until you turn on **Available to Customers**, so you can set one up and publish it when you are ready.
</Info>


## Add collections

<Tabs>
  <Tab title="Sync Seeders">
    Click **Sync Seeders** to pull the newest platform collections into your library. New ones are added, and ones you already have are updated.

    <Note>
      Syncing never changes **Available to Customers**. Anything you hid stays hidden.
    </Note>
  </Tab>
  <Tab title="Add Collection">
    Click **Add Collection** to build one yourself.

    <Frame caption="The Add Collection panel, with the seeder key, type, flow JSON and availability switch">
      <img src="/images/pa/seeder-add-collection.png" alt="The Add Collection panel, with the seeder key, type, flow JSON and availability switch" />
    </Frame>

    | Field | What to enter |
    | ----- | ------------- |
    | **Name** | What tenants see. Up to 255 characters. |
    | **Seeder Key** | The collection's own id, used when you import or sync later. Lowercase letters, numbers and underscores only, such as `welcome_flow`. Each key can be used once. |
    | **Type** | **Automation**, **WhatsApp Flow**, or **Template**. |
    | **Description** | Optional. Up to 2000 characters. |
    | **Flow JSON** | The collection itself, pasted in as JSON. |
    | **Sort Order** | Where it sits in the list. Lower numbers come first. |
    | **Available to Customers** | Leave it off until the collection is ready. |

    <Note>
      Use this form to build one collection at a time. If you already have a `.json` file of collections, go to **Import** instead.
    </Note>
  </Tab>
  <Tab title="Import">
    Click **Import** to upload a `.json` file. Use this when you already have collections prepared and want them all in at once, rather than building each one by hand.

    <Frame caption="The Import page, with the upload area and the required and optional fields">
      <img src="/images/pa/seeder-import.png" alt="The Import page, with the upload area and the required and optional fields" />
    </Frame>

    Your file can hold one collection or many, up to **10 MB**.

    Every collection needs a `seeder_key`. The platform uses that key to tell collections apart:

    - **A new key** adds a new collection. It starts hidden, so turn on **Available to Customers** when you want tenants to see it.
    - **A key that already exists** updates that collection instead of creating a second one. Only the contents change. Whatever you set for **Available to Customers** stays as it is.

    <Warning>
      One bad collection rejects the whole file. Fix it and upload again.
    </Warning>
  </Tab>
</Tabs>

## Edit collections

What you can change depends on the **Source** column.

| Source | What you can do |
| --- | --- |
| **Own** | Everything. Edit it, reorder it, turn it on or off, delete it. |
| **Platform** | Turn it on or off, reorder it, or delete it. You cannot edit the name, description or contents. |
