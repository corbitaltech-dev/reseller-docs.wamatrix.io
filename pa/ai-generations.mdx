Every time a tenant asks the AI to build an automation, it is recorded here. You see what they asked for, what came out, and how many tokens it used.

Click **AI Flow → Generations** in the sidebar.

## Generation list

<Frame caption="The AI Generations log, with the prompt, status, tier and tokens for each generation">
  <img src="/images/pa/ai-generations.png" alt="The AI Generations log, with the prompt, status, tier and tokens for each generation" />
</Frame>

| Column | Description |
| ------ | ----------- |
| **Prompt** | What the tenant asked the AI to build. |
| **Customer** | Who asked. **Own workspace** means you, not a tenant. |
| **Type** | The kind of flow, such as **booking** or **support**. |
| **Status** | How it turned out. |
| **Tier** | How many tries it took. |
| **Tokens** | What it used. |
| **Generated** | When it ran. |

## Generation tiers

Every flow is checked for quality as soon as it is built. The tier tells you how many attempts that check cost you.

| Tier | What happened |
| ---- | ----------- |
| **Single** | Built once and passed. The cheapest outcome, and what you want to see most. |
| **Repaired** | It nearly passed, so the AI fixed the specific problems and checked again. |
| **Best of N** | It fell well short, so the AI built several more and kept the best one. |

<Warning>
  More tries means more tokens. A **Best of N** generation is the most expensive kind, so watch the **Tokens** column when you see one.
</Warning>

## View a generation

Open the actions menu on a row and choose **View Details**. The panel shows what was asked, how the AI scored it, and the flow it produced.

| | What it tells you |
| --- | --- |
| **Status** | Whether it passed. |
| **Tier reached** | How many tries it took. |
| **Logic score** | The mark the quality check gave it, out of 100. |
| **Provider / model** | Which AI model built it. |
| **Tokens used** | What this one generation cost. |

Below that you get the tenant's **Prompt** in full, and the **Final flow** as JSON with its node and edge count.

### Delete a generation

The same menu has **Delete**.

<Note>
  Deleting removes this record only. The flow itself stays in the tenant's workspace and keeps working.
</Note>
