Ask someone to build something and they do better work if you show them a good example first. The AI is the same. An exemplar is a finished flow you save here as a reference.

Click **AI Flow → Flow Exemplars** in the sidebar.

When a tenant asks the AI for an automation, it finds the exemplar closest to what they asked for and works from it. It writes a new flow rather than copying yours, so the result fits their request.

<Note>
  Tenants never see or choose exemplars. This all happens behind the scenes.
</Note>

<Info>
  Your exemplars are your own. A generation uses the platform's built-in library plus anything you add here, and no other reseller sees your rows.
</Info>

## Exemplar list

<Frame caption="The AI Flow Exemplars list, with each exemplar's flow type, source and status">
  <img src="/images/pa/ai-exemplars-list.png" alt="The AI Flow Exemplars list, with each exemplar's flow type, source and status" />
</Frame>

| Column | Description |
| ------ | ----------- |
| **Name** | What you called it. |
| **Flow Type** | The kind of flow it demonstrates. |
| **Source** | **platform** if it came built in, or your own if you added it. A successful tenant generation can also become one automatically. |
| **Nodes** | How many steps the flow has. |
| **Status** | Whether the AI may use it. |

<Tip>
  Switch one off and it stays in the list but drops out of generation. Useful when an exemplar is producing flows you do not like.
</Tip>

## Add an exemplar

Click **Add Exemplar** and enter the following details.

<Frame caption="The Add Exemplar panel, with the flow type, description and graph JSON">
  <img src="/images/pa/ai-add-exemplar.png" alt="The Add Exemplar panel, with the flow type, description and graph JSON" />
</Frame>

| Field | Description |
| ----- | ----------- |
| **Name** | What you call it, such as `Lead capture`. Up to 255 characters. |
| **Slug** | Its id. Lowercase letters, numbers, hyphens and underscores, and different from your other exemplars. |
| **Flow Type** | One of **lead capture**, **info bot**, **booking**, **support**, **FAQ**, or **other**. |
| **Description** | The problem this flow solves. Required, up to 2000 characters. |
| **Keywords** | Optional words that help the AI match a request to this exemplar. Up to 60 characters each. |
| **Sort Order** | Where it sits in the list. Lower numbers come first. |
| **Graph JSON** | The flow itself. Needs a `nodes` array with at least one node, and an `edges` array. |

<Info>
  **Description** is used by the AI to match tenant requests with exemplars. Describe the requirement the flow solves, such as "Book and confirm an appointment, then remind the tenant the day before."
</Info>

<Note>
  **Graph JSON** must contain both `nodes` and `edges` arrays and pass validation. The easiest way to create valid JSON is to build the flow in the automation builder and copy its structure.
</Note>

## Best practices

The AI copies the standard you set, so a sloppy exemplar teaches sloppy flows.

- **Add flows you would happily hand a customer.** Whatever you save is the bar the AI aims for.
- **Cover the requests you actually get.** One exemplar per common job beats ten variations of the same one.
- **Keep them different from each other.** Two near-identical exemplars compete for the same requests and neither adds anything.
- **A few strong ones beat many weak ones.**
