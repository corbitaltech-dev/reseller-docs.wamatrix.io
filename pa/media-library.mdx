Your logo, your email banners, the images in your templates. Upload each file once, then reuse it anywhere in the panel.

Media Library has two parts. One holds your own files, and the other shows what your tenants are storing.

## My Media

Click **Media Library → My Media** in the sidebar. Your tenants never see these files. Each of them has a separate library inside their own workspace.

<Frame caption="My Media, with the upload controls and the storage meter">
  <img src="/images/pa/media-my-media.png" alt="My Media, with the upload controls and the storage meter" />
</Frame>

### Uploading files

Click **Upload**, then drag your files in or pick them from your computer.

Use **Add Folder** to group files, so a long library stays easy to search.

| File type | Accepted formats | Largest file |
| --- | --- | --- |
| **Images** | JPG, PNG, GIF, WEBP | 5 MB |
| **Video** | MP4, 3GP | 16 MB |
| **Audio** | MP3, OGG, AAC, M4A, AMR, OPUS | 16 MB |
| **Documents** | PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, ZIP | 100 MB |

<Note>
  These formats and sizes come from WhatsApp, not from WaMatrix.io. A file that is too big here would not send anyway. Meta lists them all under [supported media types](https://developers.facebook.com/docs/whatsapp/cloud-api/reference/media).
</Note>

### Working with a file

Click a file to see its details on the right, including its size, folder, and when it was uploaded.

<Frame caption="A file selected in My Media, with the Details panel open on the right showing its size, upload date, folder, and the Copy URL, Open file and Delete buttons">
  <img src="/images/pa/media-file-details.png" alt="A file selected in My Media, with the Details panel open on the right showing its size, upload date, folder, and the Copy URL, Open file and Delete buttons" />
</Frame>

Three buttons sit at the bottom of that panel:

- **Copy URL** — copies a link to the file, so you can paste it into an email template or anywhere else in the panel.
- **Open file** — opens it in a new tab.
- **Delete** — removes it.

Select more than one file and a bar appears, with **Move** and **Delete** for the whole selection.

## Tenant Media

Click **Media Library → Tenant Media** in the sidebar. This shows what every tenant is storing, so you can track their usage and spot anyone close to their plan limit.

<Frame caption="Tenant Media, with the storage summary cards and per-tenant usage">
  <img src="/images/pa/media-tenant-media.png" alt="Tenant Media, with the storage summary cards and per-tenant usage" />
</Frame>

Four cards summarise the whole platform: **Total Tenants**, **Storage Used**, **Total Files**, and **Near Limit**.

### What you see on the screen

| Column | Description |
| ------ | ----------- |
| **Tenant** | The tenant's name. |
| **Plan** | The plan they are on. |
| **Usage** | Storage they have used. |
| **Files** | How many files they have stored. |
| **Last Sync** | When these numbers were last worked out. |

### Open a tenant's files

Click a tenant to browse everything they have stored. Their name and plan sit at the top, so you always know whose files you are looking at.

<Frame caption="One tenant's files, with the folder and type filters, a search box, and each file's name and size">
  <img src="/images/pa/media-tenant-files.png" alt="One tenant's files, with the folder and type filters, a search box, and each file's name and size" />
</Frame>

Filter by folder or file type, or search by name.

Click a file and you get the same **Copy URL**, **Open file**, and **Delete** buttons, this time acting on the tenant's file.

<Warning>
  These are your tenant's files, not yours. Deleting one removes it from their workspace and cannot be undone, so do it only when they have asked you to.
</Warning>
