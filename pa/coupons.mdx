Use coupons to offer discounts for promotions, referrals, or upgrades. Create a coupon code once, and tenants who enter it during checkout automatically receive the discount. This avoids manually changing their invoice.

## What you see on the screen

Click **Setup → Coupons** in the sidebar menu to open this page.

<Frame caption="The Coupons list, with each code's type, value, usage, expiry, and status switch">
  <img src="/images/pa/coupons-list.png" alt="The Coupons list, with each code's type, value, usage, expiry, and status switch" />
</Frame>

The list shows every coupon you've created:

- **Code** — the code a tenant types in. Click it to copy it.
- **Type** — **Percentage** or **Fixed** discount.
- **Value** — the discount amount, shown as a percentage or as a money amount in your reseller's base currency.
- **Used** — how many times the coupon has been redeemed. Shows as `used / limit` if you set a limit, or just a plain count if it's unlimited.
- **Expires** — the date the coupon stops working, or blank if it never expires.
- **Status** — a switch that turns the coupon active or inactive, without deleting it.

### Filter the list

Use the filter panel to narrow down a long list of coupons:

- **Status** — All, Active, or Inactive.
- **Type** — All, Percentage, or Fixed.
- **Expired only** — a switch. Turn it on to show only coupons that have already expired.

## Before you start

<Warning>
You cannot create a coupon until you set your reseller's base currency under [**Currency setup**](/pa/currency-setup). The **Add Coupon** button and form stay blocked, with a message telling you to set your base currency first — a coupon needs a currency to price its discount in.
</Warning>

## Creating a coupon

Click **Add Coupon** to create a new coupon.

<Frame caption="The coupon form, with the code and discount, eligibility rules, and schedule and limits">
  <img src="/images/pa/coupon-form.png" alt="The coupon form, with the code and discount, eligibility rules, and schedule and limits" />
</Frame>

The form has three parts: **Code & Discount**, **Eligibility**, and **Schedule & Limits**.

### Code & Discount

| Field | Description |
| ----- | ----------- |
| **Code** | The code the tenant types in at checkout. Letters, numbers, hyphens and underscores only, up to 40 characters. It is always saved in capital letters, so `save20` and `SAVE20` are the same code. Click **Generate** to make a random one for you, in the style `WM-SAVE10`. |
| **Type** | **Percentage** or **Fixed Amount**. This decides which discount field shows next. |
| **Description** | A note for yourself. Tenants never see it. |

<Tip>
  A coupon code cannot be reused once it is deleted. If you delete a coupon called `SAVE20`, you cannot create a new coupon with that same code. The code remains unavailable even after the original coupon is deleted.
</Tip>

Depending on the **Type** you pick, one of these two fields shows:

| Field | Shows when | Description |
| ----- | ---------- | ----------- |
| **Discount Percentage** | Type is **Percentage** | A percentage between 1 and 100. **Max discount** is optional and sets the maximum amount that can be discounted from a single order. For example, a 50% off coupon with a \$20 max discount can never reduce the order by more than \$20. |
| **Discount amount** | Type is **Fixed Amount** | A flat amount off, in your reseller's base currency. |

<Warning>
Fixed discounts do not convert between currencies. The coupon always uses the same numeric amount you entered. For example, a coupon set to 1000 always gives 1000 off, even if you later change your base currency. Keep this in mind before changing your base currency if you already have fixed-amount coupons.
</Warning>

<Note>
A discount cannot be greater than the order subtotal. If the coupon would reduce the price below zero, the discount is limited to the subtotal, so the final amount is never negative.
</Note>

### Eligibility

| Field | Description |
| ----- | ----------- |
| **Applicable plans** | Limits the coupon to the plans selected here. Leave empty to allow the coupon on all plans. |
| **Applicable billing cycles** | Limits the coupon to the selected billing cycles: **Monthly**, **Quarterly**, **Half-Yearly**, **Yearly**, or **Lifetime**. Leave empty to allow all cycles. |
| **Min order** | Sets the minimum order amount required to use the coupon. The amount is based on the reseller's base currency. Leave empty for no minimum. |
| **First payment only** | Allows the coupon to be used only by tenants who have never had a paid invoice. Turn it off to allow tenants to use the coupon on later payments as well. |

<Note>
  **First payment only** applies when a tenant first subscribes. If a tenant starts with a trial and later upgrades to a paid plan, the coupon may still be available during that first paid subscription. Keep this in mind when using this option for welcome or first-payment discounts.
</Note>

### Schedule & Limits

| Field | Description |
| ----- | ----------- |
| **Valid from** | The date and time the coupon starts working. Leave it empty to make it active immediately. |
| **Expires at** | The date and time the coupon stops working. Must be after **Valid from**. Leave it empty for a coupon that never expires. |
| **Global usage limit** | The total number of times this coupon can be used, by all tenants together. Leave it empty for no limit. |
| **Per-tenant limit** | The number of times one tenant can use this coupon. Leave it empty for no limit. This number cannot be higher than **Global usage limit** — the form will not let you save it that way. |

<Note>
  Leaving any limit or date field empty means there is no limit.
</Note>

## No stacking

A tenant can only use one coupon per order. There is no way to combine two coupon codes on the same payment, upgrade, or renewal.

## Editing and deleting a coupon

| Action | What it does |
| --- | --- |
| **Edit** | Change the coupon's details. |
| **Usage History** | See who has used the coupon, and when. See [below](#usage-history). |
| **Delete** | Remove the coupon from your list. |

<Warning>
  **Deleting a coupon cannot be undone**, and the code cannot be reused afterward (see the tip above). Historical invoices that already used the coupon keep their discount exactly as it was — deleting only stops *new* tenants from redeeming it. If you just want to pause a coupon without losing it, turn off its **Status** switch instead.
</Warning>

<Note>
  Editing a coupon's discount value only affects future uses. Every past redemption keeps a record of the discount exactly as it was at the time, so changing a coupon later never rewrites what a tenant was already charged.
</Note>

## Usage History

Open a coupon's row menu and select **Usage History** to see every time it has been redeemed.

The panel shows a **Total Discounts Applied** summary, added up by currency, followed by a **Redemptions** table:

| Column | Description |
| --- | ----------- |
| **Workspace** | The tenant who used the coupon. |
| **Used For** | What the coupon was applied to. See the table below. |
| **Discount** | The amount taken off. |
| **Status** | **Applied** or **Reversed**. See the table below. |
| **Applied At** | When the coupon was redeemed. |

### Used For labels

| Label | It means |
| --- | --- |
| **New subscription** | The tenant used the coupon when subscribing for the first time. |
| **Plan change** | Used while switching to a different plan. |
| **Renewal** | Used on a manual early renewal. |
| **Plan (offline)** | Used on a bank transfer request you approved. See [Offline payments](/pa/offline-payments). |

### Redemption status

| Status | It means |
| --- | ----------- |
| **Applied** | The discount is active on that invoice. |
| **Reversed** | The discount was later taken back — for example, because the payment it belonged to was cancelled before it settled. |

## How renewals and upgrades interact with coupons

<Info>
  A coupon never applies by itself. A tenant must type the code in again every time they want to use it — it is never carried over automatically.
</Info>

- **Automatic renewal** charges made by the payment gateway without any action from the tenant are always billed at the full price. Coupons do not apply to recurring payments, even if the tenant used a coupon when they first subscribed.
- **Manual early renewal** —Tenants can use a coupon again when they renew early. If the coupon is valid, the discount applies only to that renewal.
- **Upgrade** — Tenants can use a coupon again when upgrading to a more expensive plan. The discount is applied to the new plan's price before any [proration credit](/pa/subscriptions#upgrades-and-downgrades) is applied.

<Warning>
  **Shopify Billing does not support coupons.** Tenants paying through Shopify Billing will not see a coupon field at checkout. If a tenant needs to use a coupon, they must choose a different payment method.
</Warning>
