Every tenant on a paid or trial plan has a subscription. Use this page to see which plan a tenant is on, check their billing status, and track when their subscription renews.

When a subscription starts depends on whether the plan costs anything:

| Plan | When the subscription starts |
| ---- | ---------------------------- |
| **Free or trial** | Straight away, when the plan is assigned during [onboarding](/pa/onboarding-a-sub-tenant). There is nothing to pay. |
| **Paid — offline payment** | After you approve the tenant's bank transfer under [**Offline Payments**](/pa/offline-payments). |
| **Paid — payment gateway** | After the tenant completes checkout through a live payment gateway. |

For a paid plan, the subscription starts **only after the first payment is successfully completed**. Until then the tenant shows a **Pending Payment** status. The plan is recorded against them, but no billing period has started and nothing renews.

## What you see on the screen

Click **Sales → Subscriptions** in the sidebar menu to open this page.

| Column | Description |
| ------ | ----------- |
| **Tenant** | Name of the tenant. Click the name to view their subscription details. |
| **Plan** | Plan currently assigned to the tenant. |
| **Status** | Current subscription status. |
| **Cycle** | How often the plan is billed. See [Billing Period](#filter-the-list) below for the full list. |
| **Paid Via** | How the tenant paid, such as a payment gateway, bank transfer, or a free trial. |
| **Renews** | Date when the current billing period ends. |
| **Started** | Date when the subscription started. |

### Filter the list

Use the filter panel to narrow down a long list of tenants:

- **Status** — Trial, Active, or Expired. Billing Only and Suspended are not offered as filter choices yet, even though both appear in the **Status** column. See [Common questions](#common-questions) below.
- **Plan** — show only tenants on one plan.
- **Created From** / **Created To** — a date range for when the subscription started.
- **Expiring Soon** — tenants renewing within 7, 14, or 30 days.
- **Billing Period** — Monthly, Quarterly, Half-Yearly, Yearly, or Lifetime.
- **Paid Via** — filter by payment method, including methods you have never actually been paid with yet.
- **Trial Active** — only tenants currently on a trial.
- **Expiring This Week** — a quick toggle for this week's renewals.
- **New This Month** — tenants who started this month.

## Subscription status

| Status | Description |
| ------ | ----------- |
| **Pending Payment** | The tenant chose a paid plan but has not paid yet. They can sign in, but only to complete the payment. The subscription starts once the first payment succeeds. |
| **Trial** | Tenant is using a plan during its trial period. If the trial ends without a paid subscription, it expires directly without entering the grace or billing-only period. |
| **Active** | Subscription is active and the tenant has full access to the features included in their plan. |
| **Billing Only** | Payment is overdue. The tenant can still sign in and complete the payment, but cannot use the platform's other features until payment is successful. |
| **Suspended** | All automatic payment retries failed. The tenant can no longer access the platform. This happens automatically — it is not the same as a manual suspend by you. See the warning below. |
| **Expired** | The subscription has ended because it was not renewed. The tenant no longer has access to the plan. |

<Warning>
  **"Suspended" means two different things.**

  The **Suspended** status on this page happens on its own, when payment retries fail. You can also suspend a tenant yourself, from [Managing tenants](/pa/managing-customers#suspend-deactivate-and-reactivate).

  One does not change the other. If you suspend a tenant yourself, this page can still say **Active**, even though that tenant is locked out. To check that, look at the [tenant list](/pa/managing-customers) instead.
</Warning>

### Subscription flow

The status changes automatically based on the subscription and payment status.

<Steps>
  <Step title="Active" icon="circle-check">
    The subscription starts as **Active**. The tenant has full access.
  </Step>
  <Step title="Grace period" icon="clock">
      When the billing period ends, the tenant enters a **grace period** and keeps full access while payment is pending. This gives the tenant time to complete a payment that is still processing or has become overdue without losing access immediately.

      You can set the grace period under [**Settings → Subscription Lifecycle → Grace Period (days)**](/pa/core-platform#grace-period-suspension). It is **3 days by default**. Set it to **0** if you want the tenant to lose access as soon as the subscription expires.

    <Note>
    The **Status** column remains **Active** during the grace period. There is no separate **Grace Period** status. To check whether a tenant is in the grace period, look at the **Grace period ends** date on their subscription details page.
    </Note>
  </Step>
  <Step title="Billing Only" icon="credit-card">
    After the grace period ends, the status changes to **Billing Only**. The tenant can sign in and complete the pending payment, but other features are unavailable.

    You set how many days this lasts under [**Settings → Subscription Lifecycle → Billing Only (days)**](/pa/core-platform#grace-period-suspension). It also defaults to **3 days**.
  </Step>
  <Step title="Suspended or Expired" icon="circle-x">
    From **Billing Only**, the subscription goes one of two ways:
    - If automatic payment retries keep failing, the status changes to **Suspended** and access is stopped completely — the tenant can no longer sign in.
    - If the billing-only period ends with no payment at all, the subscription becomes **Expired**.
  </Step>
</Steps>

<Info>
  Tenants with **Billing Only** status can still sign in and complete their payment. Their full access is restored after the payment is successful. Tenants with **Suspended** status cannot sign in — the subscription must be manually reactivated or a new plan assigned.
</Info>

<Note>
 If a tenant cancels their subscription:

- **Status stays unchanged:** The **Status** column keeps its current status, usually **Active**, until the current subscription period ends.
- **Access continues:** Cancellation does not stop the tenant's access immediately.
- **Status changes later:** When the current subscription period ends, the status changes to **Expired**.
- **No Cancelled badge:** There is no separate **Cancelled** status shown in the subscriptions list.
- **Where cancellation happens:** Tenants cancel their subscription from their own billing page, not from the admin panel.
- **How to confirm cancellation:** Check the **Timeline** on the tenant's subscription details page.
</Note>

## View subscription details

Click a tenant's name to open the subscription details page.

| Section | What it shows |
| --- | --- |
| **Plan** | Plan name, price, and billing period. |
| **Timeline** | The dates on record for this subscription. See the table below. |
| **Features** | Features and limits available with the tenant's plan. |
| **Invoices** | Invoices related to the subscription, which can be opened and downloaded as PDF. |

### Timeline events

The **Timeline** only shows events that actually happened on this subscription — a fresh trial, for example, shows only **Started**.

| Event | It means |
| --- | --- |
| **Started** | The subscription was first created. |
| **Current period start** | The date the current billing period began. |
| **Current period end** | The date the current billing period ends, or ended. |
| **Grace period ends** | The last day of full access after the period ended. |
| **Suspended until** | Set only while the subscription is in the automatic **Suspended** state. |
| **Canceled** | The date the tenant asked to cancel. This is only shown for a cancelled subscription. |
| **Ends** | This date is shown only for cancelled subscriptions. The tenant keeps access until this date. Cancelling does not end access immediately; it only prevents the next renewal. The **Access ends** date is the same as the **Current period end** date that was shown when the tenant cancelled. It is shown separately so admins can see the tenant's access end date without checking the previous **Current period end** date.|

## Manage subscriptions

The Subscriptions page is mainly used to view subscription information. You cannot change the plan or renewal date from this page.

### Upgrades and downgrades

Tenants change their own plan from their billing page. You cannot start an upgrade or downgrade for them from this admin panel, but the result shows up here:

- **Upgrading** takes effect right away. If the tenant had time left on their old plan, that time is turned into a proration credit and shown as a line item on their next invoice.
- **Downgrading** never takes effect mid-cycle. The tenant keeps their current plan until the billing period ends — the downgrade only applies at the next renewal.

Both show up as a **Plan upgraded** or **Plan downgraded** event on the tenant's Timeline.
