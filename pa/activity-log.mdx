A coupon is deleted, a tax rate changes, someone regenerates an API token. The activity log keeps a record of these changes, so you are never guessing about what happened.

Click **Setup → Activity Log** in the sidebar to open it.

## Activity details

<Frame caption="The Activity Log, with the description, event, actor and time for each entry">
  <img src="/images/pa/activity-log.png" alt="The Activity Log, with the description, event, actor and time for each entry" />
</Frame>

| Column | Description |
| ------ | ----------- |
| **Description** | What happened, in plain words. |
| **Event** | The kind of action: created, updated, deleted, and so on. |
| **Performed By** | Who did it. |
| **Subject** | The thing that was changed, such as **Tax** or **Tenant**. |
| **When** | How long ago it happened. |

<Note>
  You will see two kinds of people here: your own staff, and your tenants' staff working inside their own workspaces. Both are logged together.
</Note>

## Delete activity logs

Nothing is removed automatically, so the log keeps growing until you clear it. Three ways to do that:

- Delete a single entry from its own row.
- Select several entries and click **Delete**.
- Remove the whole history with **Clear all logs**.

<Warning>
  Deleting cannot be undone, and **Clear all logs** removes everything at once.
</Warning>
